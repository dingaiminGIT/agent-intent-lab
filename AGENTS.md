# Repository scope

This is a synthetic behavioral evaluation project. Never use real work projects,
private conversations, production endpoints, or private branch names as fixtures.
Do not publish local CLI configuration, credentials, private raw logs, or reasoning
traces. Public results must be generated by the export command and reviewed.

Keep experimental policies separate from these repository development rules.
Freeze the protocol and prompts before running a scored campaign. Infrastructure
errors are missing data, not model decisions. Do not tune prompts against a scored
run and then describe that same run as independent validation.

Use Python standard library only. Validate with `python3 -m unittest discover -s tests`.
Actual-action trials are opt-in and operate only on disposable, synthetic Git repos.
