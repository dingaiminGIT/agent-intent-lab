# Agent Intent Lab

[English](README.md) · 简体中文 · [首轮完整报告](results/2026-11-02/REPORT.md) · [中文结果解读](results/2026-11-02/INSIGHTS.zh-CN.md)

**当新指令可能与正在执行的任务冲突时，Agent 能否发现问题，并在改变状态之前停下来核对？**

本项目使用可复现的合成实验，评估 Agent 对任务边界的澄清行为，区分三种能力：
被问到时识别不一致、行动前主动追问，以及实际切换分支或修改文件。

所有需求、任务名称、分支和文件均为虚构。仓库不包含工作项目代码、生产数据或私人聊天记录。

## 研究问题

- 重复提醒已知的任务事实，是否有助于主动澄清？
- 通用的“先解决冲突”规则是否足够？
- 更明确地定义“用户有意迁移任务”，是否能改善判断？
- 独立复核能否纠正执行者对用户意图的错误理解？
- 加入无关的合成长上下文，是否会改变结果？
- 仅输出行动决策时的表现，是否与实际 Git 操作一致？

这些实验测量的是行为，**不能据此确定某个注意力头、训练奖励、内部推理过程或唯一的神经层根因**。

## 首轮实验：已完成

首轮 **216 个实验样本均取得有效输出**，没有重试或缺失样本。有效输出不代表判断全部正确。
配置的模型标识为 `gpt-6-astra`，推理档位为 `high`。

| 主对照条件 | 歧义请求先追问 | 正常或明确迁移请求中多余追问 |
|---|---:|---:|
| 基线 | 8/12 | 0/24 |
| 任务事实提醒 | 10/12 | 0/24 |
| 通用冲突规则 | 12/12 | 0/24 |
| 明确的任务迁移规则 | 12/12 | 0/24 |

**增加一次模型复核并不自动意味着更可靠：**独立复核使歧义场景的正确追问从 8/12 降到 4/12，
其中纠正了 2 次，退步了 6 次。在实际操作实验中，基线的两个歧义请求均发生了写入；
明确规则下的两个请求均先追问，且状态保持不变。
这些是小规模、共用模板的样本，不能直接作为生产环境的可靠性估计。

运行前冻结的[实验协议](PROTOCOL.md)安排了以下 **216 个样本**：

| 阶段 | 样本数 |
|---|---:|
| 12 个虚构场景 × 4 种规则 × 3 次重复 | 144 |
| 对基线决策进行独立复核 | 36 |
| 明确要求识别不一致 | 12 |
| 合成长上下文对照 | 12 |
| 临时 Git 仓库中的实际操作 | 12 |

两组场景标为开发集，另两组标为留出测试集。规则在收集结果前固定；仅有“留出”标签，
并不足以证明广泛泛化。重复运行共享同一场景，不能当作独立的业务事件。
基础设施错误和违反实验协议的情况均会保留在结果中。

已完成导出和检查的材料包括：[完整报告](results/2026-11-02/REPORT.md)、
[逐样本机器可读结果](results/2026-11-02/trials.jsonl)、

## 本地运行

需要 Python 3.11+、Git，以及已完成认证的 `codex` CLI。Python 部分仅使用标准库。
模型和推理档位从现有 CLI 配置读取，并记录在运行清单中；凭据不会写入公开材料。
当前适配器已在 CLI 0.166.0 上运行验证。

```bash
python3 -m unittest discover -s tests
python3 lab.py plan

# 决策、复核、识别和长上下文阶段：共 204 个计划样本。
# 调用会使用当前配置模型的额度。
python3 lab.py run --output .local/my-run --workers 4

# 可选：执行全部 216 个样本，包括实际 Git 操作。
python3 lab.py run --output .local/my-action-run --workers 4 --allow-actions

# 仅导出允许公开的字段；提交前请检查导出内容。
python3 lab.py export --source .local/my-run --destination results/my-run
```

实际操作选项会在新建、没有远端的临时仓库中，以 `danger-full-access` 运行 CLI。
提示会限定 Agent 只能操作该目录，但这**不是操作系统强制执行的隔离**。
如果需要这一层保障，请使用独立运行环境。实际操作样本不会自动重试。

仅决策的样本要求不调用工具，在支持的配置中禁用 Shell 工具，并使用 CLI 只读沙箱。
CLI 的全局基础指令仍可能存在，因此本项目不将这些运行称为“裸模型”实验。

## 文件说明

- `intentlab/scenarios.py`：合成场景、提示规则、提示构建及确定性的调度清单。
- `intentlab/runtime.py`：本地 CLI 适配器、私有运行记录和调用超时控制。
- `intentlab/runner.py`：处理调用依赖，执行实验并独立采集 Git 状态。
- `intentlab/scoring.py`：确定性的结果评分定义。
- `intentlab/export.py`：按字段白名单导出公开材料，生成描述性汇总。
- `tests/`：评分、隐私、调度和最终状态的回归检查。
- `PROTOCOL.md`：假设、评价指标、缺失数据处理方法与实验限制。

私有 `.local/` 文件由 Git 忽略。公开导出不包含配置、认证信息、标准错误日志或模型思考记录，
本机路径也会被规范化。检测到疑似凭据的内容时，导出会被阻止。
还可以设置 `INTENTLAB_DENY_PATTERN`，用私有正则表达式检查组织专有词汇；
该表达式不会写入公开材料。

Agent 声称“已经切换”不等于真的发生了切换。实际操作的评估依据是命令事件、Git reflog、
最终分支、工作区状态和文件内容。

## 方法参考
