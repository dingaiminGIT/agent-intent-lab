# Agent Intent Lab

这个项目研究：Agent 正在处理一项任务时，用户突然指定了另一个任务的分支，
它会先核对意图，还是直接切换并修改？

所有需求、分支和文件均为虚构。项目不使用真实工作代码、线上数据或私人聊天。

## 分别测什么

1. **能否识别**：专门问它，是否能指出当前任务与新分支的差异。
2. **会否主动核对**：正常执行任务时，是否在切换、写入前追问。
3. **是否真的行动**：在临时 Git 仓库记录命令、reflog、分支和文件内容。
4. **干预是否有副作用**：用户明确承认并要求跨任务迁移时，是否仍然多余追问。

首轮计划包含 216 个实验样本。主对照固定模型，比较四种提示：基线、事实提醒、
通用冲突规则、明确的知情迁移规则。此外测试独立复核、合成长上下文与真实 Git 操作。

协议和评分规则在运行前提交，结果另行提交。超时、容量错误、缺失结果和违反实验
协议的工具调用均单列，不把未知算成成功或失败。

## 运行

需要 Python 3.11+、Git，以及已有正常认证配置的 Codex CLI。没有额外 Python 依赖。

```bash
python3 -m unittest discover -s tests -v
python3 lab.py plan
python3 lab.py run --output .local/my-run --workers 4
python3 lab.py export --source .local/my-run --destination results/my-run
```

默认不执行实际写入实验。添加 `--allow-actions` 后，会在没有远端的临时仓库进行
操作。该选项使用 CLI 的 `danger-full-access`；操作范围由提示限定，**不是操作系统
级目录隔离**。需要强隔离时请在独立环境运行。

模型和推理档位从本机配置读取，调用会使用相应额度。公开结果不包含配置、凭据、
原始私有日志或模型思考内容。发布前仍应检查导出的文件。

## 如何理解结果

- “能识别”不自动等于“会主动介入”。
- 重复样本不等于独立业务案例；计数不能直接当作线上失败概率。
- 提示规则有效，是行为层面的证据，不足以认定注意力、训练奖励或某个神经机制是根因。
- 独立复核仍由模型完成，不能当作确定性的工具门禁。
- 模型自述“已切换”“被拦截”，必须与工具记录和 Git 状态核对。
- 留出场景与开发场景仍共用模板，不能据此宣称广泛泛化。
